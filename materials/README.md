# Local Course Materials

Put raw course materials here when generating notes.

This directory is intentionally ignored by git because the GitHub Pages site is public. Do not commit instructor slides, PDFs, recordings, assignment files, or private course data unless you have explicit permission to publish them.

Recommended layout:

```text
materials/
  114-2/
    CSL/
      final/
        slides/
        code/
        cad/
```

Generated notes belong under `docs/` in both zh-TW and English.
