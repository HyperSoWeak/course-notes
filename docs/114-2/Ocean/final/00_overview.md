# 總覽 & 速查

## 化學高頻考點

### 海水基本參數

| 參數 | 數值 |
|------|------|
| 平均鹽度 | 35 PSU（每公斤海水 35g 鹽） |
| pH | ~8（偏鹼） |
| 電導率 | ~53,000 μS/cm |
| 密度 | ~1025 kg/m³ |
| 溶氧量 | ~8 ppm（表層） |
| 聲速 | ~1500 m/s |

### 海水主要離子組成（重量%）

Cl⁻ 55% > Na⁺ 30.6% > SO₄²⁻ 7.7% > Mg²⁺ 3.7% > Ca²⁺ 1.2% > K⁺ 1.1%

**濃度排列（由高至低）：氯 > 鈉 > 鎂 > 鉀**

### 鹽度測量方法

| 方法 | 精確度 |
|------|--------|
| 導電度法（Conductivity） | **最準確** |
| 氯度滴定法（Argentometric/Mohr titration） | 次之 |
| 折射法（Refractometer） | 低 |
| 比重法（Hydrometer） | 最低 |

> 標準海水是 **KCl 溶液**（非 NaCl）

### 海水元素分布類型

| 類型 | 特徵 | 例子 |
|------|------|------|
| 守恆型（Conservative） | 垂直均勻，不受生物影響 | Na, Cl, Mg, K |
| 營養鹽型（Nutrient-like） | 表層低（生物吸收），深層高（再礦化） | N, P, Si, Ba |
| 移除型（Scavenged） | 表層最高，滯留時間短 | Fe, Al, Mn, Pb |

### 滯留時間（Residence Time）

$$t = \frac{\text{Amount in ocean}}{\text{Input/Output rate}}$$

| 元素 | 滯留時間 |
|------|----------|
| Cl⁻ | 1.2 億年（最長） |
| Na⁺ | ~6800 萬年 |
| Mg²⁺ | ~1300 萬年 |
| Th（釷） | 最短 |
| Pb（鉛）| 極短（移除型） |

> 移除型元素滯留時間 < 守恆型 < 太陽系年齡

### Redfield Ratio

$$\text{C : N : P} = 106 : 16 : 1$$

- 浮游植物吸收碳氮磷的固定比例
- 有機物 C/N 比隨深度增加（N 優先礦化）

### 物質來源

| 來源 | 主要貢獻 |
|------|----------|
| 河流 | **HCO₃⁻ > Cl⁻**；主要陽離子來源 |
| 熱液（Hydrothermal） | 添加 Fe, Mn, Si；移除 Mg（交換反應） |
| 大氣/火山 | Cl⁻, SO₄²⁻ |
| SGD（海底地下水） | 營養鹽來源 |
| 底棲通量（Benthic flux） | 深海再礦化後釋放 |

### 海洋酸化

- CO₂ 增加 → 溶入海水 → H₂CO₃ → HCO₃⁻ + H⁺ → pH 下降
- CO₂ 增加不會增加 CO₃²⁻ 飽和度（反而降低）
- 大氣 CO₂ 現已 **> 400 ppm**（Keeling curve）

### 重要污染數字

| 項目 | 數值 |
|------|------|
| 微塑膠定義 | **< 5 mm** |
| 海洋每年塑膠輸入 | 800 萬噸 |
| 人類每年攝入微塑膠 | ~5 萬顆 |
| 台灣禁用臉部去角質微粒 | **2018/7/1** |
| 福島事故 | 2011/03/11，示蹤元素 **¹³⁷Cs** |
| 日本 ALPS 排水氚 | 22 TBq/yr（中國：90 TBq/yr） |
| 生物體內半衰期 | 7–14 天（fast elimination） |

## 生物高頻考點

### 雷諾數（Reynolds Number）

$$Re = \frac{\rho v L}{\mu} = \frac{\text{慣性力}}{\text{黏滯力}}$$

- Re 大 → 移動容易（海豚 >> 橈腳類）
- 低 Re 中移動策略：交替轉動附肢；**不能同時轉動**
- 黏滯力越高 → Re 越低 → 移動越困難

### Q10 溫度定律

$$Q_{10} = \left(\frac{R_2}{R_1}\right)^{\frac{10}{T_2 - T_1}}$$

> 每升溫 10°C，代謝率約加倍（Q10 = 2）  
> 燈籠魚從 500m（15°C）游到表層（25°C）：呼吸率 ×2（10°C差）

### 初級生產力

| 術語 | 定義 |
|------|------|
| GPP（基礎生產總量） | 光合作用固定的有機碳總量 |
| NPP（淨基礎生產量） | GPP − 自營生物呼吸量 |
| NEP（淨生態系生產量） | NPP − 異營生物呼吸量 ≈ 輸出至深海的有機碳 |

**光暗瓶法：**
- 暗瓶：量呼吸速率（O₂ 減少）
- 光瓶：量 NPP（O₂ 淨增加 = 光合 − 呼吸）
- **GPP = 光瓶 O₂ 增加量 + 暗瓶 O₂ 消耗量**

> 「光瓶測得基礎生產總量」→ **錯誤**；光瓶 + |暗瓶| = GPP

### 潮間帶帶狀分布（★★★常考）

| 生態系 | 分布上限 | 分布下限 |
|--------|----------|----------|
| 礁岩潮間帶 | 生理適應（乾燥耐受） | 競爭或掠食 |
| 草澤潮間帶 | 種間競爭 | 低潮線（生理限制） |

### 海洋生物多樣性影響因子

溫度（最主要）、生產力、環境穩定度、棲地多樣性、演化史差異

### 珊瑚礁生長條件

充足光照（< 30m）、水溫 18–30°C（最佳 22–28°C）、岩石底質、良好水質、低營養鹽

### 鯨豚潛水適應

長吸呼吸（提高血氧）、有彈性的肺及橫隔膜、肌肉肌紅素、肋骨可壓扁、高濃度紅血球、心跳減慢、血液集中至心腦

### 能量傳遞效率

10%（每升一個營養級損失 90%）

### 生物幫浦（Biological Pump）

光合作用固定的有機物沉降至深海的過程；只有 **1–5%** 的 NPP 最終到達海床

## 計算題重點

### 電荷平衡計算 Ca²⁺

已知：Na⁺: 470, K⁺: 10, Mg²⁺: 50, Cl⁻: 550, SO₄²⁻: 30（mmol/kg）

正電荷 = 470 + 10 + 50×2 + Ca²⁺×2 = 負電荷 = 550 + 30×2

580 + 2Ca²⁺ + 100 = 550 + 60 → 2Ca²⁺ = 610 − 680 

重新算：  
正 = 470 + 10 + 100 + 2Ca²⁺ = 580 + 2Ca²⁺  
負 = 550 + 60 = 610  
2Ca²⁺ = 30 → **Ca²⁺ = 10 mmol/kg**（但有些考題答案是 15，注意題目 SO₄²⁻ 值）

> 電荷平衡：Σ(陽離子 × 價數) = Σ(陰離子 × 價數)

### 滯留時間計算（Residence Time）

$$t = \frac{[\text{元素}]_{\text{海水}} \times V_{\text{海洋}}}{[\text{元素}]_{\text{河水}} \times Q_{\text{河水}}}$$

- 海水總量 = 1.35 × 10²¹ kg
- 河水年流量 = 3.7 × 10¹⁶ kg/yr
