# 生物多樣性（Marine Biodiversity）

> 授課：魏志潾

## 生命的分類

| 域/界 | 特徵 |
|-------|------|
| 細菌（Bacteria） | 原核，最豐富，Bacterioplankton |
| 古菌（Archaea） | 原核，極端環境；產甲烷菌 |
| 原生生物（Protists） | 真核，單細胞；矽藻、渦鞭毛藻、有孔蟲 |
| 植物（Plantae） | 真核，多細胞，有維管束 |
| 動物（Animalia） | 真核，多細胞，異營 |
| 病毒（Viruses） | 非細胞，~10³⁰ 在海洋中 |

## 主要海洋生物群

### 浮游植物（Phytoplankton）

| 類群 | 特徵 |
|------|------|
| **矽藻（Diatoms）** | 矽質殼，主要生產者，大型，有性分裂 ✓ |
| 渦鞭毛藻（Dinoflagellates） | 鞭毛，少數有毒，大爆發→赤潮；**外殼為纖維素板**（非鈣質） |
| 顆石藻（Coccolithophores） | 鈣質板，浮游植物 |
| 藍綠藻（Cyanobacteria） | 0.5–1.5 µm，寡養海域主要生產者 |

> **矽藻敘述：是大型藻類→錯誤**（是微藻）  
> **矽藻不是都行浮游生活**（部分行底棲）

### 大型藻類（Macroalgae）與海草（Seagrass）

| | 大型藻類 | 海草 |
|--|---------|------|
| 維管束 | **無** | **有** |
| 花 | 無 | 有（顯花植物） |
| 根莖葉分化 | 無（假根、葉狀體） | 有 |
| 分布 | 淺海礁岩 | 熱帶–溫帶淺海**軟底質** |

> 「大型海藻具有維管束」→ **錯誤**

## 動物界各門

### 多孔動物（Porifera）— 海綿

- 無真正組織，過濾攝食

### 刺胞動物（Cnidaria）

- 刺絲胞（nematocyst）
- 水母、珊瑚、海葵

#### 管水母（Siphonophores）

- 群體生物（colony）
- 葡萄牙戰艦水母（Portuguese man-of-war）：被螫刺後處理方式：
  - ✅ 用**海水**沖洗
  - ✅ 用 **40–50°C 熱水**浸泡（破壞毒素蛋白質）
  - ❌ **不可用淡水**（滲透壓差使刺絲細胞更多釋毒）
  - ❌ **不可用尿液**（不科學）

### 櫛板動物（Ctenophora）

- 8 排梳板（comb rows）
- 約 100 種，最大可達 1.5m
- 會發光（bioluminescent）
- **沒有刺絲胞**（與刺胞動物最大區別）

### 扁蟲（Platyhelminthes）

- 兩側對稱、無體腔、無分節
- 雌雄同體（hermaphroditic）
- 外翻咽（evert pharynx）進食

### 環節動物（Annelida）— 多毛類（Polychaetes）

- 分節（segmented）
- 每節有疣足（parapodia）+ 剛毛（setae）

### 軟體動物（Mollusca）

- 齒舌（radula）：刮食
- 頭足類（Cephalopoda）：噴射推進，速度快
- 雙殼類：殼內充氣可控制浮力
- 裸鰓類（Nudibranchs）/ 海蛞蝓：無殼，鮮豔

### 甲殼動物（Crustaceans）

- 幾丁質（chitin）外骨骼
- 代表：藤壺（barnacles）、橈腳類（copepods）、等腳類（isopods）、端足類（amphipods）、十足目（decapods：蝦/蟹/龍蝦）

#### 櫻花蝦（Sergestid shrimp）

- **半浮游生物**（meroplankton）
- 僅分布於台灣（高屏、枋寮深海峽谷，約 150m）和**日本駿河灣**
- 少數人類可直接食用的浮游動物
- 身體佈滿紅色素及發光器

### 棘皮動物（Echinodermata）

- **五輻對稱**
- 管足（tube feet）+ 水管系統
- 代表：海星、海膽、海參、陽遂足（brittle star）

### 脊索動物（Chordata）

#### 尾索動物（Urochordata）

| 類型 | 中文 | 特徵 |
|------|------|------|
| Ascidiacea | 海鞘 | 固著，成體無脊索 |
| Thaliacea | 海樽/樽海鞘（Salps） | 浮游，浮游植物 |
| Larvaceae | 尾蟲 | 浮游，保留幼體特徵 |

> 尾索動物只有幼體有脊索；有孔蟲為**原生生物（有鈣質殼）**，非脊索動物

#### 頭索動物（Cephalochordata）

- 文昌魚（Amphioxus/Lancelet）
- 終生保留脊索、神經索

#### 脊椎動物（Vertebrata）

**魚類（Fishes）**

| 類群 | 例子 | 滲透壓調節 |
|------|------|------------|
| 無頷魚（Agnatha） | 七鰓鰻、盲鰻 | — |
| 軟骨魚（Chondrichthyes） | 鯊魚、魟魚 | 保留尿素 + TMAO 調節，**無需大量飲水** |
| 硬骨魚（Osteichthyes/Teleost） | 大多數魚類 | **大量飲水**，腎臟濃縮尿液，鰓排 Na⁺/Cl⁻ |

> 淡水魚：不喝水，鰓主動吸收 Na⁺，大量排稀尿  
> 海水魚：大量喝水，腎臟排鹽，鰓排鹽

### 潛水適應

- **長吸呼吸（Apneustic breathing）**：下潛前急速深呼吸提高含氧量、排出肺部空氣減少浮力
- **有彈性的肺及橫隔膜**：最大效率換氣
- **肌肉含肌紅素（myoglobin）**：儲存 O₂，抗乳酸堆積
- **肋骨有彈性可以壓扁**：允許肺部壓縮、減少氮氣吸收
- **高濃度紅血球**：增加攜氧量
- **心跳減慢（Bradycardia）**：保存氧氣
- **血液循環調控**：優先供應心臟和大腦

### 回音定位（Echolocation）

- **氣囊（Air sac）**：改變聲音頻率（低頻測遠，高頻測近）
- **鯨蠟/前額（Melon）**：聚焦聲音、改變聲音方向

## 生物多樣性的分布與保護

### 全球分布

- 海洋表層生物多樣性受**海表溫（SST）**影響最大（Tittensor et al. 2010）
- 多樣性熱點：熱帶印度太平洋（珊瑚三角區）> 大西洋 > 太平洋東部

### 影響生物多樣性的因素

1. **溫度**——代謝率、世代時間、種化速度
2. **生產力**——生物量、物種數目、競爭、掠食
3. **環境穩定度**
4. **棲地多樣性**
5. **演化史差異**

### 大滅絕事件

| 事件 | 時間 | 說明 |
|------|------|------|
| 奧陶紀–志留紀滅絕 | ~4.4 億年前 | |
| 泥盆紀後期滅絕 | ~3.7 億年前 | |
| **二疊紀–三疊紀滅絕** | **~2.52 億年前** | **最大，71% + 57% 種類滅絕**；暖化+缺氧；底棲→游泳生物為主 |
| 三疊紀–侏羅紀滅絕 | ~2 億年前 | |
| 白堊紀–第三紀滅絕 | ~6600 萬年前 | 隕石，恐龍滅絕 |
| **第六次：全新世大滅絕** | 現在 | 人為，速度遠超背景滅絕率 |

### 為何保護生物多樣性

**生態系作用 → 生態系功能 → 生態系服務**

| 類別 | 例子 |
|------|------|
| 支持服務 | 營養鹽循環、基礎生產力 |
| 調節服務 | 碳固存、氣候調控、淨化水和空氣 |
| 提供服務 | 漁業、油氣礦業、天然化合物 |
| 文化服務 | 娛樂、教育、好奇心 |

### 海洋生物多樣性的威脅

- 過漁（過度捕撈）
- 海洋污染（都市及農工廢水）
- 棲地破壞（海岸濕地、珊瑚礁）
- 海域遊憩活動
- 氣候變遷
- 海洋廢棄物（塑膠）

### 保育守則

- 不吃魚翅、珊瑚礁魚類及甲殼類（顏色鮮豔者）
- 不傷害海洋生物、不破壞海洋環境
- 減少一次性塑膠用品
- 支持海洋保護區（Marine Protected Area）
