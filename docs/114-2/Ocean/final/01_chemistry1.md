- **Robert Boyle**（1627–1691）：首位系統測量海水化學性質，1674 年公開發表
- Alexander Marcet（1819）：海水主要組成固定比例（守恆性）
- Alfred Redfield：提出 Redfield Ratio

## 海水的物理化學性質

| 參數 | 數值 |
|------|------|
| 平均鹽度 | **35 PSU**（每公斤海水含 35g 鹽） |
| pH | **~8**（偏鹼性） |
| 電導率 | **~53,000 μS/cm** |
| 密度 | ~1025 kg/m³ |
| 表層溶氧 | **~8 ppm**（受溫度、鹽度、壓力影響） |

### 鹽度定義

- **S = 35**：每公斤海水中溶有 35g 鹽
- 單位：PSU（Practical Salinity Unit）或 g/kg
- 標準海水（測量電導率用的標準）：**KCl 溶液**（非 NaCl）

### 鹽度測量方法（準確度排序）

1. **導電度法（最準確）** — 現代主流
2. 氯度滴定法（Argentometric/Mohr titration）
3. 折射法
4. 比重法（最不精確）

## 海水主要離子組成

| 離子 | 重量% | 濃度（mmol/kg） |
|------|--------|-----------------|
| Cl⁻ | 55.0% | ~550 |
| Na⁺ | 30.6% | ~470 |
| SO₄²⁻ | 7.7% | ~28 |
| Mg²⁺ | 3.7% | ~53 |
| Ca²⁺ | 1.2% | ~10 |
| K⁺ | 1.1% | ~10 |

**濃度由高至低：Cl⁻ > Na⁺ > Mg²⁺ > K⁺**

## 溶解氣體

### 溶解氧（O₂）

- 表層：高（光合作用 + 大氣交換），~8 ppm
- 氧最低層（Oxygen Minimum Zone, OMZ）：200–1000m（呼吸作用消耗 > 補充）
- 深層：略回升（冷水沉降時攜帶氧氣）
- 影響因子：溫度（↑溫 → ↓溶解度）、鹽度、壓力、穿透度（光照影響光合）

> **穿透度（Transmittance）不影響溶氧量**——穿透度影響的是光合作用速率，但本身不是溶解度的直接控制因子

### 溶解 CO₂ 系統

$$\text{CO}_2 + \text{H}_2\text{O} \rightleftharpoons \text{H}_2\text{CO}_3 \rightleftharpoons \text{HCO}_3^- + \text{H}^+ \rightleftharpoons \text{CO}_3^{2-} + 2\text{H}^+$$

- 海水中最穩定（濃度最高）的形式：**HCO₃⁻**（碳酸氫根）
- CO₂ 增加 → H⁺ 增加 → pH 下降（海洋酸化）
- CO₂ 增加會**降低** CO₃²⁻ 濃度（不會增加）

## 物質來源

### 主要輸入途徑

| 來源 | 特徵 |
|------|------|
| **河流** | HCO₃⁻ > Cl⁻（河水），主要陽離子及矽酸鹽來源 |
| **熱液（Hydrothermal vents）** | 添加 Fe²⁺、Mn²⁺、Si；**移除 Mg²⁺**（Mg 與熱液岩石反應） |
| **大氣沉降（Aeolian）** | Fe（沙塵）、SO₄²⁻、Cl⁻ |
| **海底地下水（SGD）** | 可能是重要的營養鹽來源 |
| **底棲通量（Benthic flux）** | 深海沉積物中有機物礦化後釋放的元素 |

> **雨水：SO₄²⁻ 濃度 > HCO₃⁻ 濃度**（大氣中 SO₂ 溶解）  
> **河水注入：HCO₃⁻ > Cl⁻**

### 台灣陰陽海（瑞芳）

- 成因：Fe²⁺（無色/淡綠）與 Fe³�⁺（棕紅）的氧化還原轉換
- 礦山廢水（含 Fe²⁺）流入海水後氧化成 Fe³⁺，形成黃棕色

### 龜山島海底熱泉

- 含**大量硫磺**（H₂S）
- 強酸性（pH 可至 2），高溫

## 元素在海水中的分類

### 三種垂直分布型態

```
守恆型（Conservative）
─────────────────  → 均勻分布，不隨生物活動改變
例：Na, Cl, Mg, K, Ca（近似守恆）

營養鹽型（Nutrient-like）
表層低（被浮游植物吸收）→ 深層高（有機物再礦化）
例：NO₃⁻, PO₄³⁻, Si

移除型（Scavenged）
表層較高（輸入近表層）→ 迅速被顆粒吸附移除 → 深層極低
例：Fe, Al, Mn, Pb（滯留時間極短）
```

> **溶解鐵（Fe）在海水中屬於移除型（Scavenged）**

### 電荷平衡計算

正電荷 = 負電荷：

$$\text{Na}^+ + \text{K}^+ + 2\text{Mg}^{2+} + 2\text{Ca}^{2+} = \text{Cl}^- + 2\text{SO}_4^{2-}$$

---

## 滯留時間（Residence Time）

$$t = \frac{\text{總量（Amount in ocean）}}{\text{輸入/輸出速率（Rate）}}$$

| 元素 | 滯留時間 |
|------|----------|
| Cl⁻ | **~1.2 億年**（最長） |
| Na⁺ | ~6800 萬年 |
| Mg²⁺ | ~1300 萬年 |
| Ca²⁺ | ~100 萬年 |
| Fe | 數百年（極短，scavenged） |

> 滯留時間最短的元素 → 移除型（如 Th 釷、Pb 鉛）

## 溫鹽環流（Thermohaline Circulation）

- 由溫度和鹽度差異驅動的大洋環流
- 極地冷水密度大下沉，驅動全球深海水循環
- 搬運熱量與碳
