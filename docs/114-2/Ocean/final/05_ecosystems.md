# 海洋生態系（Marine Ecosystems）

> 授課：魏志潾

## 海洋生物的分類（按棲息方式）

| 類別 | 定義 | 例子 |
|------|------|------|
| 浮游生物（Plankton） | 隨水流漂移，無主動游泳能力 | 浮游植物、浮游動物 |
| 游泳生物（Nekton） | 可主動游泳 | 魚類、頭足類、海洋哺乳類 |
| 底棲生物（Benthos） | 棲息於海床 | 海膽、珊瑚、底棲魚 |

---

## 大洋帶狀分區

```
表層海（Epipelagic）    0–200m    有光層
中間層（Mesopelagic）  200–1000m  微光層（Twilight zone）
深海層（Bathypelagic） 1000–4000m 無光層
深淵層（Abyssopelagic）4000–6000m
深淵溝（Hadalpelagic） >6000m
```

**底棲分區：**
```
沿岸帶（Littoral）
大陸棚（Continental Shelf） 0–200m
大陸斜坡（Slope）
漸深帶（Bathyal） 200–4000m
深海帶（Abyssal） 4000–6000m
深淵帶（Hadal）   >6000m
```

## 浮游生物

### 浮游植物（Phytoplankton）

增加浮力的適應：
- 增加體表面積（板狀突起、棘刺）
- 體內累積脂肪或油滴（**不是體型增大**）
- 身體扁平狀

> ❌「體型增大以增加浮力」→ 錯誤；應是增加面積或減輕比重

### 浮游動物（Zooplankton）

| 類別 | 例子 |
|------|------|
| 有孔蟲（Foraminifera） | 鈣質殼，真核原生生物（**非脊索動物**），星沙 |
| 放射蟲（Radiolaria） | 矽質殼 |
| 橈腳類（Copepods） | 最重要的浮游動物，磷蝦的食物 |
| 磷蝦（Krill） / 櫻花蝦 | 鯨魚的食物 |
| 樽海鞘（Salps/Thaliacea） | 桶狀，以薄膜濾食，浮游植物 |

> **樽海鞘（Salps）是浮游植物 → 錯誤**；樽海鞘是浮游動物（尾索動物）

## 游泳生物

### 鮪魚（Tuna）— 特殊適應

- **流線型體型**（hydrodynamic）
- 胸鰭、背鰭堅硬，降低阻力
- 紅肌（red muscle）：有氧代謝，持久游泳
- **隆骨（Keel）**：穩定尾部擺動
- 尾鰭槽（groove for caudal fin）：收起側鰭增加流線
- **胸甲（Corselet）**：前胸鱗片特化，穿越水流
- **反遮蔽色（Countershading）**：背部深色，腹部淺色
- 可**調節體溫**（partial endothermy）：維持肌肉高效運作
- 平均時速 **60–80 km/hr**
- 每年 4–6 月為交配產卵期

### 集群行為（Schooling）

好處：
1. **避敵**：混淆掠食者視線（confusion effect）、稀釋效果（dilution effect）
2. **覓食**：傳遞食物位置訊息
3. **繁殖**：增加相遇機率

### 座頭鯨泡泡網捕食（Bubble-Net Feeding）

- 合作行為：群體螺旋游動，吐出氣泡形成「牆」包圍魚群
- 鯡魚對座頭鯨的嘴口迎面速度（約 2–3 m/s）大於鯡魚的逃跑反應距離

## 中間層（Mesopelagic）帶特殊適應

**地球最大規模遷徙**：許多中間層生物白天躲在深處，夜晚升至表層覓食

### 燈籠魚（Lanternfish / Myctophids）

- 體側發光器（photophores）
- 日夜垂直遷移（Diel Vertical Migration）

### 斧頭魚（Hatchetfish）

- **管狀眼（Tubular eyes）**：只能朝上看
- **副視網膜（Secondary retina）**：側向視野
- 腹部發光器（counterillumination）

### 透明頭魚（Barreleye, *Macropinna microstoma*）

- **透明頭部**（充滿液體）
- 眼睛可旋轉從向前到朝上 90°

### 中間層頭足類

- **凹陷（Pit）**：眼睛有特殊凹陷允許向上注視，同時維持向側視野

### 食物稀缺的深海策略

- 吃任何食物（廣食性）
- 最大化攝食效率（大口、大胃）
- 最小化移動（低代謝率）
- 低代謝率、緩慢游泳

### 鮟鱇魚（Anglerfish）

- 極端**性別差異（Sexual dimorphism）**
- 雄魚極小，找到雌魚後**融合於雌魚身體**，成為永久寄生器官
- 雌魚用發光誘餌（lure）吸引獵物

## 能量傳遞（Trophic Pyramid）

每升一個營養級，能量損失 **90%**（效率 10%）

$$10,000,000 \rightarrow 1,000,000 \rightarrow 100,000 \text{ kcal}$$

## 潮間帶（Intertidal Zone）

### 主要挑戰

1. **水分散失（Desiccation）**：退潮時暴露在空氣中
2. **波浪衝擊（Wave impact）**

### 礁岩潮間帶生物帶狀分布

```
↑（陸地方向）
  上潮間帶：玉黍螺（Periwinkles）+ 地衣（Lichens）+ 殼狀藻
  中潮間帶：藤壺（Barnacles）為主
  中潮間帶：貽貝（Mussels）+ 藤壺 + 藻類
  下潮間帶：藻類（Seaweeds）+ 衝浪草（Surf grass）
↓（海洋方向）
```

| 分布限制 | 礁岩潮間帶 | 草澤潮間帶 |
|----------|------------|------------|
| **分布上限** | 生理適應（乾燥耐受） | 種間競爭 |
| **分布下限** | 競爭或掠食 | 低潮線（生理限制） |

### 礁岩潮間帶適應

**抗波浪：**
- 藤壺（Barnacles）：分泌黏液附著
- 貽貝（Mussels）：足絲（byssus）附著；集體應對波浪可增強穩定性
- 帽貝（Limpets）：吸盤（suction）

**殼形態與熱調節（Nerita plicata）：**
- 高殼（Tall shell）→ 減少太陽輻射截面積
- 低殼+大足（Low shell + large foot）→ 增加太陽輻射但導熱好
- 淡色、有紋理外殼（Pale, textured shell）→ 增加反射、再輻射

**殼形態與波浪適應：**
- 流線型外殼（Streamlined）→ 無湍流
- 有紋理外殼（Textured）→ 減少正面阻力

**海葵：**
- 遮蔽水流：觸手展開
- 強波浪：縮扁成低矮圓錐形

**海藻（Kelp）：**
- 靜水：垂直站立
- 強水流：彎曲，葉片折疊

### 基石物種（Keystone Species）

- Robert Paine 的礁岩潮間帶實驗
- 移除海星（Pisaster）→ 貽貝大量繁殖→物種多樣性**降低**
- 海星是控制貽貝的關鍵掠食者

## 紅樹林（Mangroves）

**定義**：生長在熱帶亞熱帶潮間帶及河口泥灘地的木本植物

### 三大特徵

1. **耐鹽保水構造**：葉片革質而厚，鹽腺能聚積並排除鹽分
2. **寬廣的根系**：支持根（prop roots）+ 呼吸根（pneumatophores），適應缺氧環境
3. **胎生幼苗（Vivipary）**：種子在母株上發芽後落地

### 台灣紅樹林分布（4 種）

| 地區 | 主要種類 |
|------|----------|
| 北部 | 水筆仔純林 |
| 新竹至嘉義 | 水筆仔 + 海茄苳混合林 |
| 台南 | 海茄苳 + 五梨跤 + 欖李 |
| 屏東 | 海茄苳純林 |

### 生態功能

- 有機碎屑溢出效應：**72–91%** 輸出至鄰近沿岸生態系（Li et al. 2018）
- 支持近海食物網及漁業（育幼場）
- 與珊瑚礁、海草床互相聯通

## 草澤生態系（Salt Marshes）

- 以**耐鹽植物（halophytes）**為主體
- 分布在溫帶至寒帶的軟底質海岸
- 鹽草有特殊腺體排除鹽分
- 生產力高，但少被動物直接食用 → 以**碎屑**方式輸出至鄰近群聚

### 植物帶狀分布

| | 礁岩潮間帶 | 草澤潮間帶 |
|--|-----------|-----------|
| 上限 | 生理適應 | **種間競爭** |
| 下限 | 競爭掠食 | **生理限制（低潮線）** |

### Bottom-up vs. Top-down 控制

- **Bottom-up（上行控制）**：由營養鹽/光照控制生產者，影響整個食物網
- **Top-down（下行控制）**：由捕食者控制（掠食者 → 草食動物 → 植物）
- **Trophic Cascade（營養瀑流效應）**：頂端掠食者的移除引發整個食物鏈的連鎖反應

> Brian Silliman 草澤實驗：排除蝸牛（草食動物）→ 互花米草（Spartina）茂盛

## 亞潮帶（Subtidal）/ 陸棚生態系

### 軟底質（Soft-bottom）

**生物分類：**
- **底表生物（Epifauna）**：底質表面覓食的動物（端足目、蝦、陽遂足、織紋螺）
- **底內生物（Infauna）**：底質內部生活的動物（沙蠶、錐蟲、燐蟲、鳥蛤、心形海膽）

**底內生物按大小分類：**

| 類別 | 大小 | 例子 |
|------|------|------|
| Macrofauna | > 0.5 mm | 蠕蟲、貝類 |
| **Meiofauna** | 0.063–0.5 mm | 動吻動物、腹毛動物、緩步動物、線蟲 |
| Microbiota | < 0.063 mm | 渦鞭毛藻、矽藻、細菌 |

**Meiofauna 代表生物：**
動吻動物（Kinorhynch）、腹毛動物（Gastrotrich）、緩步動物（Tardigrada/水熊）、輪蟲（Rotifer）、猛水蚤（Harpacticoida）、線蟲（Nematode）

- 溶氧受底質顆粒大小影響（細泥 → 缺氧嚴重）
- 面臨的問題：氧氣供應不足 + 捕食者威脅

### 硬底質（Hard-bottom）

- 岩石底質群聚（Rocky bottom）
- 海藻林（Kelp community）：溫寒帶，高營養鹽
- 珊瑚礁（Coral reefs）：熱帶

## 珊瑚礁（Coral Reefs）

**生長條件：**
- 生產力最高的環境之一
- 充足光照（通常水深 **30m 以內**）
- 水溫：18–30°C，最佳 **22–28°C**
- 需要**岩石底質**
- 需要**良好水質**（低營養鹽、低懸浮物）

> ❌ 「優養化水域是珊瑚生長的條件」→ 錯誤

### 珊瑚蟲（Coral Polyp）結構

- 刺絲胞（Nematocyst）：捕食/防禦
- 外胚層（Epidermis）/ 中膠層（Mesoglea）/ 內胚層（Gastrodermis）
- 柱狀體（Columella）：碳酸鈣骨骼的基礎

### 共生藻（Zooxanthellae）

- 生活在珊瑚內胚層中
- 行光合作用，提供珊瑚 **> 90% 的能量**
- 賦予珊瑚鮮豔的顏色

### 珊瑚白化（Bleaching）

環境劇變（高溫、強光、污染）→ 珊瑚**失去共生藻** → 露出白色碳酸鈣骨骼

### 珊瑚生殖

- **無性生殖**：出芽生殖（budding）、斷裂生殖（fragmentation）
- **有性生殖**：配子釋放受精

**珊瑚同步產卵：**
- 滿月後觸發（光信號控制）
- 機制（Lin et al. 2021 PNAS）：滿月前：日落前月亮已升起 → **抑制**產卵；滿月後：日落後月亮才升起（有一段黑暗）→ **觸發**產卵
- **沿岸光害使珊瑚提早同步產卵**（Davies et al. 2023 Nat Commun）

> 同步產卵的優點：增加受精成功率、減少掠食、增加基因多樣性

### 珊瑚礁類型

| 類型 | 中文 | 說明 |
|------|------|------|
| Fringing reef | **裙礁** | 緊鄰海岸；墾丁、小琉球 |
| Barrier reef | **堡礁** | 與海岸有潟湖相隔；大堡礁 |
| Atoll | **環礁** | 由火山島下沉後形成；東沙環礁、馬爾地夫 |

**成因（Darwin 理論）：**
裙礁（火山島沿岸）→ 火山島下沉 → 堡礁 + 潟湖 → 繼續下沉或海平面升高 → 環礁

### 台灣珊瑚礁

- 寶石珊瑚（Precious coral）：生長緩慢，無共生藻，靠有機顆粒為食
  - 現在捕獲的多為**化石**，顯示資源量已崩潰
  - **無法永續經營**（非再生資源）
- 東沙環礁國家公園：海草床、礁魚、檸檬鯊幼鯊（育幼場）

## 總結

- 大洋生態系可分為有光和無光層，主要影響因子：光強度及食物來源，皆隨深度銳減
- 有光層浮游生物：增加浮力、透明化、垂直遷移
- 游泳生物：運動、感覺、偽裝或群游
- 潮間帶生物需適應水分喪失和波浪衝擊
- 控制潮間帶生物分布：生理適應 + 生物間交互作用（競爭、掠食、基石物種效應、上行下行控制）
- 珊瑚礁為海洋中生產力最高的環境，依賴共生藻
- 約只有 **1–5%** 的 NPP 落到海床，支持除化學合成外約 99% 的底棲生態系統
