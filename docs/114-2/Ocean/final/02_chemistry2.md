# 化學 II：生地化反應循環與污染

> 授課：溫良碩

## 主要營養鹽

| 元素 | 形態 |
|------|------|
| 氮 N | NO₃⁻, NO₂⁻, NH₄⁺, NH₃, N₂, urea |
| 磷 P | HPO₄²⁻, PO₄³⁻, H₂PO₄⁻ |
| 硫 S | SO₄²⁻, H₂S |
| 矽 Si | H₄SiO₄, H₃SiO₄⁻, H₂SiO₄²⁻ |

### Redfield Ratio

$$\text{C : N : P} = 106 : 16 : 1$$

- 健康浮游植物吸收碳氮磷的固定比例
- 微量元素（Fe）和維他命對某些藻類也可能是限制因子
- 有機物中 C/N 比隨深度**增加**（N 在淺水優先礦化）

## 碳泵

### 溶解度泵（Solubility Pump）

- CO₂ 在冷水中溶解度更高
- 極地冷水密度大下沉 → 帶著溶解 CO₂ 沉入深海
- 涼水上升（upwelling）時釋放 CO₂

### 生物泵（Biological Pump）

$$\text{光合作用} \rightarrow \text{有機物} \rightarrow \text{下沉} \rightarrow \text{再礦化（深海）}$$

- 過程：浮游植物固碳 → 被浮游動物攝食 → 排出糞粒下沉 → 細菌分解 → 無機碳釋回深層水
- 僅 **1–5%** 的 NPP 到達海床
- 有機碳輸出到深海的機制**與顆粒密切相關**（沉降顆粒採集器需大口設計）
- 懸浮顆粒採集需大體積海水

## HNLC（High Nutrient Low Chlorophyll）

- 區域：南極海、北太平洋、赤道太平洋
- 特徵：有大量 N、P 但葉綠素低（生產力低）
- 原因：**微量元素鐵（Fe）限制**浮游植物生長

### 鐵假說（Iron Hypothesis）

- 提出者：**John Martin**，1981 年
- 首次在**南極海域**採集海水並進行鐵添加培養實驗
- 後續驗證：Ironex I、II（1993, 1995）在赤道太平洋鐵施肥實驗

> Martin 名言："Give me half a tanker of iron, and I'll give you an ice age."

## 海洋酸化（Ocean Acidification）

$$\text{CO}_2 + \text{H}_2\text{O} \rightarrow \text{H}_2\text{CO}_3 \rightarrow \text{HCO}_3^- + \text{H}^+ \rightarrow \text{pH} \downarrow$$

- 大氣 CO₂ 增加 → 海水 pH 下降
- 現在大氣 CO₂ **> 400 ppm**（Keeling curve, Mauna Loa）
- 冰期 CO₂ 濃度低 → 海水 pH **高於**間冰期
- CO₂ 增加**降低** CO₃²⁻ 飽和度（有害貝殼/珊瑚等鈣化生物）
- 並非所有鈣化生物都受負面影響

---

## 優養化與死亡區

### 優養化（Eutrophication）

過多營養鹽輸入 → 藻類大量生長 → 死亡分解 → 細菌消耗大量 O₂ → 缺氧

**Trophic State Index（TSI）**

| 等級 | 狀態 |
|------|------|
| Oligotrophic | 寡養 |
| Mesotrophic | 中營養 |
| Eutrophic | 優養 |
| Hypereutrophic | 超優養 |

### 死亡區（Dead Zones）

- **低氧（Hypoxia）**：O₂ < 2 mg/L
- **無氧（Anoxia）**：O₂ ≈ 0%
- 代表案例：墨西哥灣死亡區（密西西比河農業污染帶入大量 N、P）
- 全球已有 **400+** 個死亡區

> Dead zone 缺乏的是**氧氣（O₂）**，而非其他元素

## 核污染

### 福島事故

- 日期：**2011/03/11**
- 示蹤元素：**¹³⁷Cs（銫-137）**——用來追蹤海洋核污染擴散
- ¹³⁷Cs 在海洋生物體內生物半衰期：**7–14 天**（代謝較快）
- ALPS 處理水排放：日本 22 TBq/yr 氚（tritium）vs 中國 ~90 TBq/yr

> 監測核電廠外洩主要監測 **¹³⁷Cs**（非 ¹⁸O、²¹⁰Pb、¹⁴C）

## 海洋塑膠污染

### 規模

- 每年進入海洋：**約 800 萬噸**
- 99% 「失蹤」的塑膠（沉入海床、被生物攝食等）
- 大太平洋垃圾帶（Great Pacific Garbage Patch）

### 微塑膠（Microplastics）

- 定義：直徑 **< 5 mm** 的塑膠顆粒
- 初級微塑膠（Primary microplastics）：臉部去角質顆粒、工業原料
- **台灣禁用含微粒臉部去角質產品：2018/7/1**
- 微塑膠存在於：雨水、雪、冰川、海鹽（海鹽 > 湖鹽 > 岩鹽）
- 人類每年攝入：~50,000 顆

### 生物影響

- 海龜受塑膠氣味吸引（誤食塑膠）
- 含塑膠微粒的海洋生物廣泛記錄
- 台灣環保署研究（2018）：自來水清水 100 件，**44 件**驗出微塑膠

### 奈米銀（AgNP）

- 大小：1–100 nm
- 毒性：抑制 **Na/K ATPase**（破壞離子幫浦）
