# 海洋環境（Marine Environment）

> 授課：魏志潾

## 海水特性

| 特性 | 說明 |
|------|------|
| 密度 | ~1025 kg/m³（比淡水重），隨溫度↓/鹽度↑而增加 |
| 黏滯性（Viscosity） | 決定物質沉降速度及生物運動 |
| 聲速 | ~1500 m/s（比空氣快） |
| 水分子特性 | 一個 O + 兩個 H；O 帶負電，H 帶正電；氫鍵使水分子平均與另 4 個分子以**正四面體**結構連結 |

---

## 雷諾數（Reynolds Number）

$$Re = \frac{\rho v L}{\mu} = \frac{\text{慣性力}}{\text{黏滯力}}$$

| 因子 | 與 Re 的關係 |
|------|-------------|
| 密度（ρ）、速度（v）、體長（L）越大 | Re 越大 |
| 黏滯力（μ）越大 | Re 越小 |

- **Re 大 → 移動容易**（海豚 Re >> 浮游動物 Re）
- **低 Re 環境**（小型浮游生物）：慣性力 << 黏滯力，像在糖漿中游泳
- 低 Re 中有效移動策略：**持續振動**或**交替轉動附肢**
- ❌ **同時轉動附肢不利於低 Re 移動**（時間對稱運動，無淨位移）

## 滲透壓調節

### 海水魚（Teleost）— 海水環境，魚體鹽度 < 海水

| 機制 | 說明 |
|------|------|
| 大量喝水 | 補充因滲透失去的水分 |
| 腎臟濃縮尿液 | 減少水分流失 |
| **鰓排 Na⁺, Cl⁻** | 主動分泌 |

> **不是腎臟排鹽而是鰓排鹽**——「腎臟排鹽」錯誤

### 淡水魚 — 淡水環境，魚體鹽度 > 淡水

- 不喝水；**鰓主動吸收 Na⁺**；大量排稀尿

### 軟骨魚（鯊魚等）

- 保留高濃度尿素 + **TMAO（氧化三甲胺）**調節滲透壓
- 體液滲透壓 ≈ 海水，不需大量飲水

## Q10 溫度定律

$$Q_{10} = \left(\frac{R_2}{R_1}\right)^{\frac{10}{T_2 - T_1}}$$

> 每升溫 10°C，代謝率約加倍（Q10 ≈ 2）

**例題：** 燈籠魚從 500m（15°C）游到表層（25°C），Q10 = 2  
→ 溫差 = 10°C → 呼吸率 **×2**（乘兩倍）

## 恆黏度適應（Homeoviscous Adaptation）

- 低溫下細胞膜流動性降低 → 增加不飽和脂肪酸比例以維持膜流動性
- 生物在不同溫度環境中調節細胞膜的物理特性

## 光線穿透

- **真光層（Euphotic zone）**：光照 > 1% 表面光強度的水層（約 0–200m）
- 葉綠素 a 吸收峰：**430nm（藍光）** 和 **680nm（紅光）**
- 紅光在最淺水中被吸收；藍光穿透最深
- **深層葉綠素最大值（DCM, Deep Chlorophyll Maximum）**：位於真光層底部/溫躍層上方

## 壓力適應

$$P = \rho g d$$

| 深度 | 壓力 |
|------|------|
| 每 10m 增加 1 atm | 8336m = ~825 atm ≈ 391 棟台北 101 疊起來 |

### TMAO（氧化三甲胺，Trimethylamine N-oxide）

TMAO 是深海魚的**壓力適應蛋白**（piezolyte）兼**滲透壓調節物**：

1. **穩定蛋白質結構**，抵抗高壓對蛋白質的破壞
2. **滲透壓調節**（osmolyte）：在軟骨魚中與尿素共同維持滲透壓
3. **[TMAO] 隨深度線性增加**

- 在 ~8000m，魚類 TMAO 濃度達到**與海水等滲透的極限（isosmotic limit）**，這可能是深海魚的棲息深度上限
- TMAO 分解 → **TMA（三甲胺）** = 魚腥味
- 酸性調味料（醋、檸檬汁）可**抑制**此轉換（故加醋去腥有效）

**Hirondellea gigas**（馬里亞納端足類）：有 Ca + Al 構成的外骨骼（非純幾丁質）以抵抗深海壓力

## 初級生產力

**定義**：自營生物（autotrophs）利用太陽能或化學能，將 CO₂ 轉化為有機碳的速率（g C/m²/yr）

### 光合作用

**光反應：**
$$2\text{H}_2\text{O} + \text{光} \rightarrow 4[\text{H}^+] + \text{energy} + \text{O}_2$$

**整體反應：**
$$6\text{CO}_2 + 6\text{H}_2\text{O} + 48 \text{ photons} \rightarrow 6\text{O}_2 + \text{C}_6\text{H}_{12}\text{O}_6$$

### 化學合成（Chemosynthesis）

$$6\text{CO}_2 + 6\text{H}_2\text{O} + 3\text{H}_2\text{S} \rightarrow \text{C}_6\text{H}_{12}\text{O}_6 + 3\text{H}_2\text{SO}_4$$

- 環境：**黑煙囪（black smokers）**、冷泉（cold seeps）、鯨落（whale falls）
- 此類生態系不依賴陽光

### 生產力定義

| 術語 | 定義 |
|------|------|
| **GPP**（基礎生產總量） | 光合作用固定的有機碳總量 |
| **NPP**（淨基礎生產量） | GPP − 自營生物呼吸量 |
| **NEP**（淨生態系生產量） | NPP − 異營生物呼吸量 ≈ 輸出至深海顆粒 |

> NEP ≈ 向下輸出到深海的顆粒及溶解態有機物  
> NEP = NPP − 異營生物呼吸（**不是** NPP − 自營生物呼吸）

### 光暗瓶法

| 瓶 | 測量量 |
|----|--------|
| 暗瓶 | O₂ 消耗 = 呼吸速率（R） |
| 光瓶 | O₂ 淨增加 = NPP = 光合 − R |
| **GPP** | **= 光瓶 O₂ 增加 + 暗瓶 O₂ 消耗** |

> ❌ 「光瓶測得基礎生產總量（GPP）」→ **錯誤**；光瓶只測 NPP  
> ❌ 「暗瓶測得基礎生產總量」→ 錯誤；暗瓶測呼吸

### 全球初級生產力分布

| 生態系 | 生產力 (g C/m²/yr) |
|--------|-------------------|
| 藻床/珊瑚礁 | 最高，~2500 |
| 沿岸湧升流區 | ~500–1500 |
| 開放大洋 | ~50–150 |
| 寡養熱帶海洋 | 最低 |

- 海洋植物生物量只有陸域植物的 **1/100**
- 但海洋植物轉換率（**天**）遠快於陸域（**年**）→ 海洋與陸地總生產力大致相同

### 衛星遙測

- 利用水色（water color）→ 推算葉綠素 a 濃度
- 用 MODIS、SeaWiFS 等衛星感測器

## 營養鹽在海中的分布

### 深度剖面

```
表層 → 生物吸收 → 低（nutrient limitation）
真光層底 → DCM（葉綠素最大值）
溫躍層下方 → 有機物礦化 → 高
```

- 無機氮（N）、磷（P）在深層高，表層低（營養鹽型分布）
- 溫度：thermocline（溫躍層），混合層（mixed layer）在表層

### 貧養 vs. 富養海域的營養鹽循環

| | 貧養熱帶亞熱帶 | 富養溫帶寒帶 |
|--|---------------|--------------|
| 浮游植物 | 小型（藍綠藻，0.5–1.5 µm） | 大型（矽藻，5–100 µm） |
| 浮游動物 | 單細胞（1–100 µm） | 大型多細胞（> 200 µm） |
| 循環效率 | 90% 留在表層循環 | 50% 留在表層 |
| 沉降輸出 | 少（NEP 低） | 多（NEP 高） |

> 熱帶：小型浮游植物主導，高效循環；溫帶：大型矽藻主導，高輸出效率
