# 樹

## 基本定義

- **樹（Tree）**：連通無環無向圖
- **森林（Forest）**：無環無向圖（可能不連通）；每個連通分量是一棵樹
- **葉節點（Leaf）**：度數為 1 的頂點

### 樹的等價條件（Thm 83）

以下對 $n$ 個頂點的圖 $G$ 等價：

1. $G$ 是樹
2. $G$ 連通且 $|E| = n - 1$
3. $G$ 無環且 $|E| = n - 1$
4. 任意兩頂點之間有**唯一**的路徑

## 森林的頂點-邊公式

**Thm**：設 $F = (V, E)$ 為森林，$\kappa$ = 連通分量（樹）的數量。則

$$|V| = |E| + \kappa$$

> **證明**：設 $\kappa$ 棵樹分別有 $V_1, \ldots, V_\kappa$ 個頂點、$E_1, \ldots, E_\kappa$ 條邊。
> 每棵樹滿足 $|V_i| = |E_i| + 1$（樹的性質）。
> $$|V| = \sum_{i=1}^\kappa |V_i| = \sum_{i=1}^\kappa (|E_i| + 1) = |E| + \kappa \quad \blacksquare$$

## 有根樹（Rooted Tree）

- **根（Root）**：指定一個頂點作為根
- **深度（Depth）**：頂點到根的距離
- **高度（Height）**：樹的最大深度
- **$m$-ary 樹**：每個內部節點最多 $m$ 個子節點
- **完全 $m$-ary 樹**：每個內部節點恰好 $m$ 個子節點

## 二元樹（Binary Tree）

- 每個節點最多 2 個子節點（左子樹 $T_L$，右子樹 $T_R$）

**有序二元樹計數**：$n$ 個節點的有序二元樹共有 $C_n = \frac{1}{n+1}\binom{2n}{n}$（Catalan 數）個（但以考試來說，$n=4$ 有 **14** 個）

### 二元樹總路徑長

**$f(T)$** = 所有節點的深度之和。

**Thm**：若 $T$ 有 $n$ 個節點：

$$f(T) = f(T_L) + f(T_R) + n - 1$$

> **證明**：設 $d(x, T)$ 為節點 $x$ 在 $T$ 中的深度。
> - $T$ 的根深度 = 0，不計入 $f(T_L)$ 或 $f(T_R)$。
> - $T_L$ 中每個節點 $x$ 的深度：$d(x, T) = d(x, T_L) + 1$。
> - 同理 $T_R$ 中每個節點深度 +1。
> - $T$ 有 $n$ 個節點，其中 $T_L$ 有 $n_L$ 個，$T_R$ 有 $n_R$ 個，$n_L + n_R = n - 1$（不含根）。
>
> $$f(T) = f(T_L) + n_L + f(T_R) + n_R = f(T_L) + f(T_R) + (n-1) \quad \blacksquare$$

## 考古題

### 【必考】森林 $|V| = |E| + \kappa$（2024、2025、2024s）

**題目**：設 $F = (V, E)$ 為森林，$\kappa$ 為樹的數量。證明 $|V| = |E| + \kappa$。

**解答**：

對森林中的每棵樹 $T_i$（$i = 1, \ldots, \kappa$），設其有 $|V_i|$ 個頂點、$|E_i|$ 條邊。

由樹的性質（Thm 83）：$|V_i| = |E_i| + 1$。

對所有樹求和：

$$|V| = \sum_{i=1}^{\kappa} |V_i| = \sum_{i=1}^{\kappa} (|E_i| + 1) = \sum_{i=1}^{\kappa} |E_i| + \kappa = |E| + \kappa \quad \blacksquare$$

**解答**：見上方定理的證明。$\blacksquare$

### 14 棵有序二元樹（$n=4$ 節點）（2018）

**題目**：畫出所有 14 棵有序有根二元樹（4 個節點）。

**答**：$C_4 = \frac{1}{5}\binom{8}{4} = 14$。這 14 棵樹對應不同的樹形結構。常見結構有：

- 右斜鏈：根 → 右 → 右 → 右（高度 3）
- 左斜鏈：根 → 左 → 左 → 左（高度 3）
- 根有左右子樹（各種組合）
- 完全二元樹形狀（高度 2）

（考試需畫出所有 14 種，不能遺漏）
