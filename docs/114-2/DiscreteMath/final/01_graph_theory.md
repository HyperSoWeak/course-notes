# 圖論

## 基本定義

- **圖** $G = (V, E)$：$V$ = 頂點集合，$E$ = 邊集合
- **度數** $\deg(v)$：與 $v$ 相鄰的邊數；握手定理：$\sum_{v} \deg(v) = 2|E|$
- **簡單圖**：無自環、無重邊
- **二部圖** $G = (V_1, V_2, E)$：$E \subseteq V_1 \times V_2$

## Euler 路徑與迴路

### 無向圖

| 條件 | 存在性 |
|------|--------|
| 連通 + 所有頂點度數為偶數 | Euler **迴路** |
| 連通 + 恰好 2 個頂點奇度數 | Euler **路徑** |

### 有向圖

- 有**有向 Euler 迴路** ↔ 強連通 且 每個頂點 in-degree = out-degree
- 強連通：對任意 $a \neq b$，存在 $a \to b$ 的有向路徑

## 平面圖

**Euler 公式**：設 $G$ 為連通平面圖，$v$ = 頂點數，$e$ = 邊數，$r$ = 面數：

$$v - e + r = 2$$

**邊數上界**（Thm）：簡單連通平面圖，$e > 2$：

$$e \leq 3v - 6$$

> **證明**：每個面的邊界 $\geq 3$ 條邊；每條邊最多被 2 個面共用。
> $$2e \geq 3r \Rightarrow r \leq \frac{2e}{3}$$
> 代入 Euler 公式 $2 = v - e + r \leq v - e + \frac{2e}{3} = v - \frac{e}{3}$，得 $e \leq 3v - 6$。

### 二部圖的平面限制

若 $G$ 是連通二部圖（每個面邊界 $\geq 4$）：

$$e \leq 2v - 4$$

## 二部圖與邊數

**Thm（非二部圖判定）**：$G = (V, E)$ 為簡單無向圖。若

$$|E| > \left(\frac{|V|}{2}\right)^2$$

則 $G$ 不是二部圖。

> **證明**：若 $G$ 是二部圖，$|V_1| = m$，$|V_2| = n - m$，則 $|E| \leq m(n-m)$。
> 乘積最大值在 $m = n/2$ 時取得，此時 $m(n-m) \leq (n/2)^2 = (|V|/2)^2$。
> 因此若 $|E| > (|V|/2)^2$，則矛盾。

## 著色數與 Clique

- **著色數** $\chi(G)$：著色 $G$ 所需最少顏色數（相鄰頂點不同色）
- **Clique**：完全子圖；最大 clique 的大小記為 $\omega(G)$

**$\chi(G) \geq \omega(G)$**（clique 內所有頂點互相鄰接，需要不同顏色）

**但 $\chi(G) = \omega(G)$ 不一定成立！**

> **反例**：奇數頂點的圈（奇圈），如 $C_5$（五角形）。
> - $\chi(C_5) = 3$（因為是奇圈，2 色不夠）
> - $\omega(C_5) = 2$（圈中沒有三角形）
> - 因此 $\chi(G) \neq \omega(G)$

## 考古題

### 【必考】$|E| > (|V|/2)^2 \Rightarrow$ 非二部圖（2024、2024s）

**題目**：設 $G = (V, E)$ 為無自環無向圖。證明：若 $|E| > \left(\frac{|V|}{2}\right)^2$，則 $G$ 不是二部圖。

**解答**：

若 $G$ 是二部圖，令 $G = (V_1, V_2, E)$，$|V| = n$，$|V_1| = m$，$|V_2| = n - m$。

則 $|E| \leq |V_1| \cdot |V_2| = m(n-m)$。

對 $m(n-m)$ 求最大值：由 AM-GM 不等式（或對 $m$ 求導），最大值在 $m = n/2$ 時取得：

$$m(n-m) \leq \left(\frac{n}{2}\right)^2 = \left(\frac{|V|}{2}\right)^2$$

因此若 $|E| > (|V|/2)^2$，則 $|E| > m(n-m)$，矛盾。故 $G$ 不是二部圖。$\blacksquare$

### 【必考】$\chi(G)$ 是否等於最大 clique 大小（2024、2025、2024s）

**題目**：設 $G = (V, E)$ 為無向圖，$\chi(G)$ 為最少著色數，clique 為完全子圖。試證明或反駁：$\chi(G) =$ 最大 clique 的大小。

**解答**：命題**為假**。反例：

取 $G = C_5$（5 個頂點的圈：$v_1 - v_2 - v_3 - v_4 - v_5 - v_1$）。

- **$\chi(C_5) = 3$**：$C_5$ 是奇圈，不能 2-著色（因為不是二部圖）；3 種顏色可以著色（例如 1,2,1,2,3）。
- **最大 clique 大小 = 2**：圈中每條邊形成大小為 2 的 clique，但圈中沒有三角形，故最大 clique 大小為 2。

因此 $\chi(G) = 3 \neq 2 =$ 最大 clique 大小，命題不成立。$\blacksquare$

### 有向 Euler 迴路 ↔ 強連通（2018）

**題目**：
1. 有向圖有有向 Euler 迴路，是否必然強連通？
2. 反過來，強連通是否必然有有向 Euler 迴路？

**解答**：

1. **True**：若有向 Euler 迴路 $C$，對任意 $x \neq y \in V$，迴路 $C$ 經過 $x$ 與 $y$，故存在 $x \to y$ 與 $y \to x$ 的有向路徑，圖是強連通的。

2. **False**（反例）：考慮下圖：

$$a \to b \to c \to a, \quad a \to d \to a$$

此圖強連通（任意兩點間有有向路徑），但 $b$ 的 out-degree = 1，in-degree = 1；$d$ 的 out-degree = 1，in-degree = 1；$a$ 的 out-degree = 2，in-degree = 2。

實際上，更簡單的反例：4 個頂點 $a, b, c, d$ 形成強連通，但某頂點 in-degree $\neq$ out-degree，故不存在有向 Euler 迴路。$\blacksquare$

### 平面圖 $e \leq 3v - 6$ / 互補圖不能都是平面圖（2018）

**題目**：設 $G = (V, E)$ 為有 $|V| \geq 11$ 個頂點的無環連通無向圖，$\bar{G}$ 為其補圖。證明 $G$ 與 $\bar{G}$ 不能同時為平面圖。

**解答**：

設 $|V| = n \geq 11$，$e = |E|$，$e' = |\bar{E}|$。

若 $G$ 是平面圖：$e \leq 3n - 6$。  
若 $\bar{G}$ 是平面圖：$e' \leq 3n - 6$。

但 $G$ 的總邊數加補圖邊數 = $\binom{n}{2}$，故：

$$e + e' = \binom{n}{2} = \frac{n(n-1)}{2}$$

對 $n = 11$：$e + e' = \binom{11}{2} = 55$，而 $3n - 6 = 27$，故若兩者都是平面圖則 $e + e' \leq 27 + 27 = 54 < 55$，矛盾。$\blacksquare$

對一般 $n \geq 11$：$\binom{n}{2} = \frac{n(n-1)}{2} > 6n - 12$ 當 $n \geq 11$。
