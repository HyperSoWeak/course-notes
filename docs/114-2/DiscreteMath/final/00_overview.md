# 離散數學期末 — 總覽 & 速查

## 定理速查表

### 圖論

| 定理/引理 | 內容 |
|---------|------|
| **Euler 迴路** | 無向圖有 Euler 迴路 ↔ 連通且每個頂點度數為偶數 |
| **Euler 路徑** | 無向圖有 Euler 路徑 ↔ 連通且恰有 2 個奇度頂點 |
| **有向 Euler 迴路** | 有向圖有 Euler 迴路 ↔ 強連通且每個頂點 in-degree = out-degree |
| **平面圖** | $v - e + r = 2$（Euler 公式，$r$ 為面數） |
| **邊數上界** | 簡單連通平面圖：$e \leq 3v - 6$（$e > 2$） |
| **二部圖上界** | $\|E\| \leq \lfloor \|V\|^2/4 \rfloor$；$\|E\| > (\|V\|/2)^2 \Rightarrow$ 非二部圖 |
| **著色數 vs 最大团** | $\chi(G) \geq$ 最大团大小，但**不一定相等**（奇圈反例：$\chi = 3$，最大团 = 2） |

### 樹與森林

| 定理/引理 | 內容 |
|---------|------|
| **樹** | 連通無環圖；$n$ 個節點恰有 $n-1$ 條邊 |
| **森林** | $\|V\| = \|E\| + \kappa$（$\kappa$ 為樹的棵數） |
| **二元樹路徑長** | $f(T) = f(T_L) + f(T_R) + n - 1$ |

### 環

| 定理/引理 | 內容 |
|---------|------|
| **Thm 102** | 環的單位元唯一；乘法逆元唯一 |
| **Cor 99** | $a \cdot z = z \cdot a = z$（$z$ = 加法單位） |
| **Cor 101** | $-(−a)=a$；$a\cdot(-b) = -(ab)$；$(-a)(-b)=ab$ |
| **Thm 104** | 每個 field 都是 integral domain |
| **Thm 105** | 有限 integral domain 是 field |
| **CRT** | $x \equiv a_i \pmod{n_i}$，$\gcd(n_i,n_j)=1$ ⟹ 有唯一解 mod $N = \prod n_i$ |

### 群

| 定理/引理 | 內容 |
|---------|------|
| **Thm 107/108** | $H \leq G$ ↔ 非空 + 封閉 + 逆元；有限群只需封閉 |
| **Lemma 111** | $a^k = e \Rightarrow o(a) \mid k$ |
| **Thm 117 (Lagrange)** | $\|H\|$ 整除 $\|G\|$ |
| **Cor 118** | $o(a)$ 整除 $\|G\|$ |
| **Thm 119** | $a^{\|G\|} = e$（任意有限群） |
| **Thm 120 (Euler)** | $a^{\varphi(n)} \equiv 1 \pmod{n}$，$\gcd(a,n)=1$ |
| **Thm 121 (Fermat)** | $a^{p-1} \equiv 1 \pmod{p}$，$p$ 素數 |
| **Cor 122** | 素數階群為循環群 |
| **Lemma 129** | 相同階的循環群同構 |
| **Cor 130** | 階 $n>1$ 的循環群同構於 $(\mathbb{Z}_n, +)$ |
| **Homomorphism** | $f(x \circ y) = f(x) \circ' f(y)$；$f(e_G)=e_H$；$f(x^{-1})=f(x)^{-1}$ |

### 置換

| 定理/引理 | 內容 |
|---------|------|
| **Thm 131** | $o(g) = \text{lcm}$（所有循環的長度） |
| **Thm 132** | $g^{-1} \circ f \circ g$：對 $f$ 的循環分解中每個符號套用 $g$ |
| **共軛** | $f \sim h$ ↔ $\exists g: g^{-1} \circ f \circ g = h$；共軛是等價關係 |

### 軌道 & Burnside

| 定理/引理 | 內容 |
|---------|------|
| **Thm 140 (Burnside)** | \#軌道 $= \frac{1}{\|G\|}\sum_{g \in G}\|F(g)\|$，$F(g) = \{x: g(x)=x\}$ |
| **Thm 141 (Orbit-Stabilizer)** | $\|O_x\| = \|G\| / \|G_x\|$ |

## 關鍵公式

$$\varphi(n) = n\prod_{p \mid n}\left(1 - \frac{1}{p}\right)$$

$$\text{CRT: } x = \sum_{i=1}^k a_i \cdot m_i \cdot (m_i^{-1} \bmod n_i) \pmod{N}$$

$$\text{Burnside: \#orbits} = \frac{1}{|G|}\sum_{g \in G}|F(g)|$$

$$o(f \circ g \text{ 的循環分解}) = \text{lcm}(\text{各循環長度})$$
