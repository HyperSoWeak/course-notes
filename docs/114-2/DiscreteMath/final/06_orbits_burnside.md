# 軌道、穩定子與 Burnside 引理

## 群作用（Group Action）

設群 $G$ 作用在集合 $X$ 上：對每個 $g \in G$，$g: X \to X$ 是 bijection，且：
- $e(x) = x$（單位元是恒等映射）
- $(g_1 \circ g_2)(x) = g_2(g_1(x))$（合成保持）

## 軌道（Orbit）

**軌道** $O_x = \{g(x) : g \in G\}$（$x$ 在 $G$ 作用下能到達的所有位置）

**Lemma 136**：所有軌道劃分 $X$（不相交且覆蓋全部）。

**Lemma 137**：$i$ 與 $j$ 在同一軌道 $\Leftrightarrow$ $\exists g \in G : g(i) = j$。

## 穩定子（Stabilizer）

**穩定子** $G_x = \{g \in G : g(x) = x\}$（固定 $x$ 不動的所有群元素）

**Lemma 138**：$G_x$ 是 $G$ 的子群。

> **證明**：
> - 非空：$e \in G_x$
> - 封閉：$g_1, g_2 \in G_x \Rightarrow (g_1 \circ g_2)(x) = g_2(g_1(x)) = g_2(x) = x$
> - 逆元：$g \in G_x \Rightarrow g^{-1}(x) = g^{-1}(g(x)) = x$

**Lemma 139**：若 $i, j$ 在同一軌道，則 $|G_i| = |G_j|$。

## Orbit-Stabilizer 定理（Thm 141）

$$|O_x| = \frac{|G|}{|G_x|} = [G : G_x]$$

> **原因**：$G$ 的左陪集（以 $G_x$ 為子群）與 $O_x$ 的元素一一對應。

## Burnside 引理（Thm 140）

設 $G$ 有限群作用在有限集 $X$ 上，令 $F(g) = \{x \in X : g(x) = x\}$（$g$ 的**不動點集**）。

**軌道的數量 = $G$ 中所有元素不動點數的平均值**：

$$\text{\#orbits} = \frac{1}{|G|} \sum_{g \in G} |F(g)|$$

> **記憶方式**：「每個群元素平均固定幾個元素」= 軌道數。

## 考古題

### Burnside 計算：$\pi = (1\;6)(2\;5)(3\;4)$（2018）

**題目**：$G = \langle \pi \rangle = \{I, \pi\}$，$X = \{1,2,3,4,5,6\}$。用 Burnside 引理求軌道數。

**解答**：

$|G| = 2$，計算 $|F(g)|$：
- $F(I) = X$（所有元素都是 $I$ 的不動點），$|F(I)| = 6$
- $F(\pi) = \emptyset$（$\pi = (1\;6)(2\;5)(3\;4)$ 無不動點），$|F(\pi)| = 0$

$$\text{\#orbits} = \frac{1}{2}(6 + 0) = 3$$

驗證：軌道為 $\{1,6\}$，$\{2,5\}$，$\{3,4\}$，共 3 個。$\blacksquare$

### Burnside 引理典型應用（計算不同著色數）

**例**：用 3 種顏色對正方形的 4 個頂點著色，旋轉視為相同，有幾種本質不同的著色？

$G = \{r_0, r_{90}, r_{180}, r_{270}\}$（旋轉群，$|G| = 4$），$X = $ 所有 $3^4 = 81$ 種著色。

計算 $|F(g)|$（著色數使得 $g$ 將著色映射到自身）：
- $|F(r_0)| = 3^4 = 81$（恒等，全部固定）
- $|F(r_{90})| = 3^1 = 3$（4 個頂點必須同色）
- $|F(r_{180})| = 3^2 = 9$（對角頂點同色，2 對）
- $|F(r_{270})| = 3^1 = 3$（同 $r_{90}$）

$$\text{\#orbits} = \frac{81 + 3 + 9 + 3}{4} = \frac{96}{4} = 24$$

### Orbit-Stabilizer 定理：$|O_x| \cdot |G_x| = |G|$

**例**：若 $G = S_4$（$|G| = 24$），$G$ 作用在 $\{1,2,3,4\}$ 上，$x = 1$。

$O_1 = \{1,2,3,4\}$，$|O_1| = 4$。

故 $|G_1| = |G| / |O_1| = 24 / 4 = 6$。

（$G_1$ 是固定 1 的置換，即 $S_{\{2,3,4\}} \cong S_3$，$|S_3| = 6$，驗證正確。）
