# 計算機系統實驗 Final Review Overview

## 怎麼讀

這份整理把課程材料重組成 6 個考試主題：

1. `01_control_pid.md`：control、dynamics、PID、Lab04 stabilizer
2. `02_structures_trusses_springs.md`：statics、truss、spring、catapult
3. `03_actuation_motors_transmission.md`：motor、friction、gear、pneumatics/hydraulics、micro actuation
4. `04_fabrication_cad_laser.md`：Fusion 360、3D printing、FEA、laser cutting joints
5. `05_hci_history.md`：Early HCI、Engelbart、Xerox PARC、Sketchpad、Memex
6. `06_final_project_boat.md`：maze solving boat 的設計重點

考前優先順序：

1. 先讀 `99_exam_quick_review.md`
2. 再讀 `01_control_pid.md`、`02_structures_trusses_springs.md`、`04_fabrication_cad_laser.md`
3. 最後補 `03_actuation_motors_transmission.md`、`05_hci_history.md`
