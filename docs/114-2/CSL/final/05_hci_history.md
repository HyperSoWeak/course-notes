# Early HCI and Computer Systems

## 課程主軸

這份投影片從 personal computing 往回看，說明 GUI、mouse、hypertext、interactive graphics 的發展不是單一公司發明，而是多個研究系統累積。

課程敘事方向是從現代產品往回追溯；考歷史順序時則反過來，從 Bush / Sutherland / Engelbart 往 Xerox、Apple、Microsoft 看。

## Vannevar Bush

Vannevar Bush 在 1945 年提出 `Memex` 的概念。

重點：

- Memex = memory extender
- 用 microfilm 想像個人資訊管理系統
- 提到 associative trails，接近 hypertext 的想法
- 也想像 wearable cameras、automatic speech transcripts、information flood
- 當時尚未把 digital computer 視為主要實現方式

考試句：

```text
Bush imagined information augmentation before practical personal computers existed.
```

## Ivan Sutherland

1962 `Sketchpad`：

- first interactive graphics
- 用 light pen 直接操作圖形
- 支援 constraints / graphical editing 的早期概念
- 對 CAD 和 graphical interaction 影響大

## Douglas Engelbart

1968 `Mother of All Demos` 展示：

- mouse
- interactive text editing
- 2D editing
- hypertext
- document version control
- groupware / shared screen teleconferencing
- context-sensitive help
- collaborative real-time editor

Engelbart 的核心不是 automation，而是 augmentation：

```text
computer should augment human intellect, not simply replace humans with automation.
```

他也有 dead ends，例如 foot mouse、chorded keyboard。重點是 early HCI 不是只有成功產品，也包含大量 interaction experiment。

## Xerox PARC

Xerox Alto：

- 1973 internal version
- bitmap display
- GUI / desktop metaphor
- Ethernet
- laser printing

Xerox Star：

- 1981 shipped
- 推動 desktop publishing 和 WYSIWYG
- 但太貴、太晚，投影片稱為 second system syndrome

## Apple / Microsoft / Xerox 的關係

投影片主張：

- Microsoft learned from Apple
- Apple learned from Xerox
- Xerox learned from Engelbart / earlier research

但課程重點不是「誰偷誰」，而是創新常來自 research prototype、productization、timing、cost 的交互作用。

## 考試整理

| Person / System | Contribution |
|---|---|
| Vannevar Bush / Memex | associative information trails, hypertext-like vision |
| Ivan Sutherland / Sketchpad | interactive graphics, early CAD |
| Douglas Engelbart / NLS | mouse, hypertext, collaborative editing, augmentation |
| Xerox Alto / Star | GUI, desktop metaphor, Ethernet, laser printing, WYSIWYG |
| Apple Macintosh | GUI personal computing productization |
| Microsoft Windows | GUI mainstream adoption |

答題方向：

- 說明 technology lineage
- 區分 invention、research prototype、commercial product
- 提到 augmentation vs automation
