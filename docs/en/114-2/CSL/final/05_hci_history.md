# Early HCI and Computer Systems

## Main Lineage

The course traces personal computing backward:

```text
Microsoft -> Apple -> Xerox PARC -> Engelbart / Sutherland -> Bush
```

Historically, read the line in the opposite direction: Bush, Sutherland, and Engelbart influenced Xerox PARC, which influenced Apple and later Microsoft.

The point is not only who invented what, but how research prototypes, commercial products, cost, and timing interact.

## Vannevar Bush

In 1945, Bush proposed `Memex`, a memory extender based on microfilm.

Key ideas:

- associative trails
- information augmentation
- hypertext-like navigation
- wearable cameras
- automatic speech transcripts
- information overload

Bush imagined information systems before practical personal computers existed.

## Ivan Sutherland

`Sketchpad` in 1962:

- early interactive graphics
- direct graphical manipulation
- constraints and graphical editing
- major influence on CAD and HCI

## Douglas Engelbart

The 1968 `Mother of All Demos` showed:

- mouse
- interactive text editing
- 2D editing
- hypertext
- document version control
- groupware
- shared screen teleconferencing
- context-sensitive help
- collaborative real-time editing

Engelbart emphasized augmentation rather than automation:

```text
Computers should augment human intellect instead of simply replacing human work.
```

The experiments also included dead ends such as foot mouse and chorded keyboard.

## Xerox PARC

Xerox Alto:

- internal system in 1973
- bitmap display
- GUI and desktop metaphor
- Ethernet
- laser printing

Xerox Star:

- shipped in 1981
- WYSIWYG and desktop publishing influence
- too late and too expensive, described as second-system syndrome
